# Рекомендация книг с помощью коллаборативной фильтрации

### План проекта

1. Загрузка данных
   - Импорт данных в проект из файлов csv

2. EDA
   - Поиск в интеренете отствующих данных.
   - Исследование данных для выявления закономерностей.
     

3. Обработка данных
   - Преобразование и подготовка данных для последующего анализа и моделирования.
   - Расчет взвешенного рейтинга
  

4. Создание модели
   - Создания pivot-таблицы 
   - Создание функции рекомендации на основе косинусной меры похожести.

5. Сериализация
   - Сохранение данных c помощью библиотеки 'pickle'.

6. Интерактивный дашборд
    - Создание интерактивного дашборда с пощью фреймворка 'streamlit'.
